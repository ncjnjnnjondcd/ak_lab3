Проєкт мінімальної вбудованої системи Linux для платформи BeagleBone Black

## Структура репозиторію
- **`configs/`** — конфігураційні файли збірки (.config) для U-Boot, Linux Kernel та BusyBox.
- **`rootfs_overlay/`** — системні файли ініціалізації (стартовий скрипт `rcS`).
- **`scripts/`** — допоміжні скрипти запуску емуляції в QEMU.
- **`docs/`** — технічні нотатки та опис конфігурації.
